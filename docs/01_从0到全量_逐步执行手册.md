# 二、第一层测试：离线 smoke

这一步不依赖 Hugging Face 和 Edge-TTS 网络，使用 `tests/fixtures/sujet_mini.jsonl`，通过 mock TTS 生成标准 24 kHz MP3，再经过与生产相同的 FFmpeg、Audio QC、JSONL 代码。

```bash
bash run_build.sh --mode smoke
```

默认输出：

```text
./data_test/mock/
```

看报告：

```bash
cat data_test/mock/reports/FINAL_BUILD_REPORT.md
```

看最终 JSONL：

```bash
head -n 1 data_test/mock/final/all.jsonl | python -m json.tool
```

必须看到：

```json
{
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "<audio>Please answer the financial question in the audio."},
    {"role": "assistant", "content": "原始 answer"}
  ],
  "audios": ["/absolute/path/...wav"]
}
```

user message 里不能出现原问题 transcript。

检查 WAV：

```bash
WAV=$(find data_test/mock/audio_16k -name '*.wav' | head -n 1)
ffprobe -v error -show_entries stream=sample_rate,channels,codec_name -of default=nw=1 "$WAV"
```

应看到：

```text
codec_name=pcm_s16le
sample_rate=16000
channels=1
```

# 三、第二层测试：真实 Sujet + 真实 Edge-TTS 小样本

只有离线 smoke PASS 后才执行。

## Step 1：真实 5 条测试

```bash
mkdir -p /ky200t/datasets/$USER/.cache/huggingface

bash run_build.sh \
  --mode live-smoke \
  --output-root ./data_test/live \
  --limit 5 \
  --hf-cache-dir /ky200t/datasets/$USER/.cache/huggingface
```

`live-smoke` 对 HF 使用 streaming，只取前 N 条 `qa`，避免为了 5 条测试在当前目录冻结完整 Sujet parquet。

## Step 2：检查真实测试结果

```bash
cat data_test/live/reports/FINAL_BUILD_REPORT.md
```

要求：

```text
tts_success_rows > 0
audio_qc_pass_rows == final_rows
final_validation_error_count == 0
```

随机试听 2～3 个音频，重点听金融数字、百分比、bps、10-K/10-Q、ETF/EPS/SEC、金额数量级。

发音词典只修改：

```text

```

确认后再全量。

# 十、常见问题

## 1. Edge-TTS 网络/NoAudioReceived

直接重跑同一 full 命令。单条有 retry，全局有 resume。持续失败时先 `live-smoke --limit 1`，不要先提高并发。

## 2. Hugging Face 下载失败

检查：

```bash
echo "$HF_ENDPOINT"
```

服务器已有 HF 镜像时通常自动生效。

## 3. `ffmpeg: command not found`

用户没有 sudo，联系管理员。

## 4. `/ky200t` Permission denied

确认写自己目录 `/ky200t/datasets/$USER/`；仍失败联系管理员。

## 5. VSCode 断线任务停了

说明没有在 tmux 中运行。重新在 tmux 启动 full，已有 WAV 会复用。

## 6. 想改变全量位置

换 `--output-root` 即可。所有 WAV、manifests、JSONL 均相对于本次 output root 管理。
