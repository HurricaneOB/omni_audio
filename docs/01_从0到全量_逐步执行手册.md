# Sujet 金融音频数据集：从 0 到全量构建逐步执行手册（v1.0.1 smoke 修复版）

> 目标：把 Sujet `task_type == "qa"` 的 `user_prompt` 合成为真实英文金融问题语音，把原始 `answer` 原样作为 assistant 文本监督，输出 Qwen3-Omni / ms-swift `messages + audios` JSONL。

# 二、先理解四种模式

| 模式 | Source | TTS | 音频有语义吗 | 用途 |
|---|---|---|---:|---|
| `offline-smoke` | 本地 fixture | `test-tone` | 否 | 纯离线结构回归 |
| `smoke` | 本地 fixture | 真实 Edge-TTS | 是 | 第一层真实语音验收 |
| `live-smoke` | 真实 Sujet streaming | 真实 Edge-TTS | 是 | 第二层真实数据验收 |
| `full` | 完整 Sujet | 真实 Edge-TTS | 是 | 正式全量构建 |

**旧版 `smoke` 使用 mock/test tone 的语义已经废止。**


```text

```

**不要试听它来判断 TTS 是否正确，也不要把该目录用于训练。**

# 四、第一层真实语音测试：smoke

现在 `smoke` 使用：

```text
本地 tests/fixtures/sujet_mini.jsonl
+
真实 Edge-TTS
```

因此不会下载完整 Sujet，但必须能访问 Edge 在线服务。

执行：

```bash
bash run_build.sh --mode smoke
```

默认输出：

```text
./data_test/smoke_edge/
```

成功结束时必须看到：

```text
[BACKEND-GUARD][PASS] backend=edge
```

检查 backend：

```bash
python - <<'PY'
import json
p='data_test/smoke_edge/manifests/edge_voice_snapshot.json'
x=json.load(open(p,encoding='utf-8'))
print('backend =', x['backend'])
print('voice_count =', x['voice_count'])
print('first_voice =', x['voices'][0]['Name'])
PY
```

必须：

```text
backend = edge
```

并且 voice 名不能是：

```text
test-tone-*
```

# 十三、旧 `data_test/mock` 怎么处理

旧版 `smoke` 产生的：

```text
./data_test/mock/
```

如果其中 WAV 是纯音测试文件，建议直接删除，避免与真实 smoke 混淆：

```bash
rm -rf ./data_test/mock
```

修复版真实 smoke 使用新的目录：

```text
./data_test/smoke_edge/
```

因此不会与旧结果混在一起。
